## Fuel is causal

expensive attempts and rhythm mismatch consume fuel. Regulation, balance and
high-quality success restore it. Low fuel and low balance before crystallization
trigger ROZPAD I. ROZPAD I can return to REGULACJA in the same cycle; if recovery
fails, the incomplete organization reaches 40 without intuitive retention.

## Second collapse

1. actual KRYSTALIZACJA;
2. entry into RYTM;
3. persistent mismatch with the main rhythm;
4. STAGNACJA;
5. PĘKNIĘCIE after persistence and loss of balance/fuel.

After ROZPAD II, state 3 separates residue from chaos, state 6 removes failures,
raw code and noise, state 28 consolidates the useful general rule, and state 40
is the transition threshold. Crossing 40 starts the next cycle through RÓŻNICA.
